# Bot de Ventas - Proyecto Final

Este proyecto consolida archivos de diferentes sucursales, limpia los datos, y genera un análisis de ventas.

## Estructura del proyecto
- `datos/`: Contiene los archivos originales (CSV y Excel).
- `resultados/`: Contiene el archivo consolidado y los gráficos generados.
- `bot.py`: Script principal en Python que ejecuta todo el proceso.
- `README.md`: Este archivo.
